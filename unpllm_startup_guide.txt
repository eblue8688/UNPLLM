========================================================
UNPLLM - PROJECT STARTUP GUIDE
========================================================
Read this top to bottom every time you sit down after a
break. Project location: ~/Desktop/UPE


STEP 1 - CHECK OLLAMA IS RUNNING
----------------------------------------
Usually already running as a background service. Verify:

    systemctl status ollama

If not active:
    sudo systemctl start ollama

Confirm your model is there:
    curl http://127.0.0.1:11434/api/tags

Look for "phi4-mini:latest" in the response.


STEP 2 - ENTER THE PROJECT AND ACTIVATE THE VENV
----------------------------------------------------
    cd ~/Desktop/UPE
    source unpllm-env/bin/activate

Your prompt should now start with (unpllm-env).


STEP 3 - (ONE-TIME CHECK) CONFIRM DEPENDENCIES ARE INSTALLED
------------------------------------------------------------------
Only needed if you're not sure last session's install finished:

    pip list | grep -E "chromadb|sentence-transformers|torch|streamlit"

All four should show up. If torch is missing, install the
CPU-only build first - it's a much smaller download than the
default (which bundles CUDA support this machine doesn't need):

    pip install torch --index-url https://download.pytorch.org/whl/cpu
    pip install -r requirements.txt


STEP 4 - START ALL THREE PROCESSES (separate terminals)
------------------------------------------------------------
The project now runs as three pieces working together. Start
each in its own terminal, with the venv activated in each:

  Terminal 1 - the API server:
      python3 main.py
  Expect: "Uvicorn running on http://127.0.0.1:8001"

  Terminal 2 - the sync engine (connectivity watcher):
      python3 sync_watcher.py
  Expect: "UNPLLM sync watcher started." then a status line.

  Terminal 3 - the chat UI:
      streamlit run app.py
  Opens a browser tab automatically at http://localhost:8501

None of these return to your prompt - that's correct, they're
all long-running. Leave all three open. Ctrl+C to stop any one.


STEP 5 - USE IT
--------------------------
Chat in the Streamlit tab that opened. The sidebar shows:
  - Live online/offline status (from sync_watcher.py)
  - When the knowledge base was last updated
  - What was recently synced

Each answer is tagged with where it came from:
  Green  = original documents      Blue = synced content
  Yellow = weak match (gap)        White = no relevant context


ADVANCED / MANUAL API TESTING (without the UI)
------------------------------------------------
Still available if you want to test the API directly:
    http://127.0.0.1:8001/docs
  - /health         -> quick check the service is alive
  - /generate       -> plain model, no retrieval
  - /generate_rag   -> retrieval-augmented answers

Remember to replace the placeholder "string" in the request
body with a real prompt before clicking Execute.


ADDING NEW NOTES TO THE KNOWLEDGE BASE
------------------------------------------------
Drop .txt or .md files into:
    ~/Desktop/UPE/documents/

Then re-run (safe to repeat any time, won't duplicate old ones):
    python3 ingest.py


CHECKING THE SYNC ENGINE'S WORK
------------------------------------------------
See what topics are still unresolved gaps:
    python3 analyze_gaps.py

Check the real RAM usage of the loaded model:
    ollama ps

Remove a specific bad sync if one ever slips through (replace
the title with whatever the sync log printed):
    python3 -c "from rag_utils import get_collection; get_collection().delete(where={'source': 'wikipedia:ARTICLE_TITLE_HERE'}); print('Removed.')"


IF SOMETHING SEEMS BROKEN
------------------------------------
"[Errno 98] Address already    -> an old main.py from a previous
in use"                           session is still running somewhere.
                                   Find and stop it:
                                     lsof -i :8001
                                     kill <PID shown>
                                   or in one line:
                                     kill $(lsof -t -i :8001)
                                   Then retry python3 main.py.

"ModuleNotFoundError"           -> forgot to activate unpllm-env

main.py runs, nothing happens   -> it's not broken. It should show
                                    "Uvicorn running..." and just
                                    sit there. Test via /docs, not
                                    by watching the terminal.

Script looks frozen              -> probably isn't. This machine is
                                     CPU-only (~4 tok/s), so
                                     generation genuinely takes a
                                     while. Give it time.

"Method Not Allowed" in browser  -> you opened /generate directly
                                     in the address bar. It only
                                     accepts POST - use /docs
                                     instead.

Streamlit sidebar says "Unknown"
status                            -> sync_watcher.py isn't running
                                     (or hasn't written its first
                                     status update yet - wait ~15s
                                     after starting it).

Sync engine fetches something
irrelevant                        -> the relevance check should
                                     catch and discard most of
                                     these automatically. Check
                                     sync_watcher.py's terminal for
                                     "doesn't look related enough"
                                     to confirm it was caught.


KNOWN HARDWARE FACTS (so you stop re-checking these)
----------------------------------------------------------
- No NVIDIA GPU on this machine (confirmed via lspci)
- phi4-mini: ~3.1 GB RAM when loaded, ~4.16 tok/s average speed
- Check live RAM/CPU usage for the loaded model any time with:
      ollama ps


LIVE DATA TOOLS (weather, air quality, currency)
------------------------------------------------
Questions like "weather in Delhi", "air quality in Hyderabad" or
"100 usd to inr" are answered by free, keyless public APIs
(Open-Meteo, Frankfurter) instead of the knowledge base. Online: live
answer. Offline: the last saved reading with its age, or an honest
"unavailable" if nothing was ever saved. Currency uses daily ECB
reference rates, not live market quotes.
Test them on this machine (needs internet):   python3 live_tools.py
Switch them all off instantly: set LIVE_TOOLS_ENABLED = False in
live_tools.py.


PROJECT FILES
-------------------------
main.py           FastAPI service (/health, /generate, /generate_rag)
app.py            Streamlit chat UI (Stage 4) - the main way to use this
sync_watcher.py   Connectivity watcher + opportunistic sync (Stage 3)
rag_utils.py      Embedding, retrieval, and storage-cap functions
query_logger.py   SQLite query log + gap-flagging (Stage 3)
gap_engine.py     Shared gap-clustering logic
analyze_gaps.py   CLI report of unresolved knowledge gaps
ingest.py         Loads documents/ into the vector database (Stage 2)
benchmark.py      Hardware benchmark script (Stage 1)
requirements.txt  All dependencies
documents/        Your source notes for the knowledge base
chroma_db/        The vector database itself (auto-created)
unpllm_queries.db SQLite log of every query + gap status
sync_status.json  Live status written by sync_watcher.py, read by app.py
live_tools.py     Live weather / air quality / currency tools
live_cache.json   Last successful live readings (offline fallback)

For setting this project up on a different computer (Windows
or Mac instead of Ubuntu), see "Switching OS.txt".
